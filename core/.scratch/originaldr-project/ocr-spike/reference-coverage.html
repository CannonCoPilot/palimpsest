Douay-Rheims reference coverage — by book and chapter

What the denominator is. This project holds no external canonical verse-count table, so a chapter's expected length is the largest count any of the four references reports for it. Coverage is therefore measured against the union of the four, which is a lower bound on the true text: a chapter shown as complete may still be short if every reference is short. Book names are the Douay-Rheims forms; the modern equivalent is given in parentheses where it differs.
