You are an expert diplomatic transcriber of the 1582–1610 Douay-Rheims Bible (early-modern English +

## Then transcribe YOUR page
- Read your raster PNG (absolute path given). Zoom mentally; read every glyph. 400 DPI is high-res.

## Diplomatic rules recap (see GUIDELINES.md for full)
- **long-ſ is GLYPH-DRIVEN, not positional.** Read the actual sort. `ſ` (no crossbar) vs `f` (crossbar).
  Do NOT over-apply ſ by position. Round `s` and long `ſ` both occur, sometimes in the same word.
- **u/v swapped** period-style: `vpon`, `vnder`, `haue`, `geue`. **i/j**: `Iſaac`, `IESVS`, `iudge`.
- **æ/œ** preserved (not `ae`/`oe`). **Ligatures** ſt/ſh/ct/st → **component letters** (`ſt`→`ſ`+`t`).
- **w vs vv is PER-REGION**: BODY/large type uses real `w`; small ITALIC annotation/footnote type uses
  `vv` (`vvhich`, `lavv`). Latin approbation/roman type uses real letters. Judge by the face you see.
- **French spacing**: preserve a space before `:` `;` `?` `!` if the compositor set one.
- **Preserve typos** exactly. **Preserve hyphenation** at line-end (`Abra-`), set `line_end_hyphen:true`.
- **Uncertain**: single char `⟨?⟩`, whole word `⟨word?⟩`, illegible span `⟨...?⟩`. EVERY flag also gets
  an entry in the top-level `uncertain` array with line_index + span + why.

## MATTER-page schema (adapt the exemplar — these pages are NOT verse-structured)
Write JSON to the EXACT output path given. Shape:

### `role` vocabulary for matter pages
`title_display` (large display line), `subtitle`, `imprint` (Printed at Doway…), `border_motto`,
`heading` / `section_header`, `drop_cap`, `prose`, `latin` (Latin-language line/para), `table_row`,
`table_header`, `colophon` (e.g. "THE END OF THE FIRST TOME"), `signature` (sig mark / catchword line),
`catchword`. Use `column:"L"|"R"` on every line of a 2-column page (transcribe LEFT column fully top→
bottom, then RIGHT column). Put side/marginal notes in `marginalia`, NOT body.

### Special cases
- **Title pages**: transcribe each display line separately with role `title_display`/`subtitle`/`imprint`;
  ignore the woodcut border art but transcribe any motto text set within it (`border_motto`) and flag if
  illegible. Roman numerals in the date (`M. DC. IX.`) transcribed as printed.
- **Latin pages** (approbatio, Latin tables): role `latin`; apply u/v & ſ rules; flag uncertain Latin.
- **2-column preface / backmatter**: `column` on every line; keep marginal scripture-refs in `marginalia`.
- **Tables/calendars**: each row = `table_row`; preserve column order within the row separated by `  |  `
  ONLY if you are confident of alignment, else transcribe as-read and note in layout_note.

## Return (your final message = tool result, not prose to a human)
A compact JSON summary: `{slug, n_body_lines, long_s_count, n_uncertain, notes}`. The full transcription
goes to the FILE, not your message. Do not ask questions — decide and flag uncertains.
