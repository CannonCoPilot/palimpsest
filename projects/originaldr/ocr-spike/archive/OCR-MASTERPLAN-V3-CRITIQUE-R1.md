# V3 — CRITIQUE ROUND 1: five specialists, and what they converged on

Five adversarial reviewers read V3 independently: an OCR/HTR training engineer, an alignment/MSA-and-collation
specialist, a document-layout researcher, a measurement/metric-gaming reviewer, and a textual scholar
specialising in early modern English printing. They did not see each other's work.

**Convergence is the signal.** Where three or more independent critics hit the same defect from different
directions, it is not a matter of taste.

---

## C1. THE PLAN HAD NO EXTERNAL REFERENT — four of five critics, independently

> *"Until that eval set exists, no CER number in this plan means anything."* (OCR)
> *"A geometric gate without geometric GT is unmeasurable, and an unmeasurable gate is the silent-degradation
> pattern §0.1 says this document exists to correct."* (layout)
> *"CER against a machine-derived ARCHAIC is not accuracy."* (scholar)
> *"D4 and D6 block everything downstream — they determine whether any board number means anything."* (measurement)

Every metric in V3 was computed against ground truth the pipeline itself generated, scored against a reference
the pipeline itself corrects. **Both the accuracy target and the layout gate were unfalsifiable as written.**

The layout critic added the sharpest form of it: `PAGE_OVERRIDE`'s 371 hand-measured bands **are** human
annotation, already paid for, in a form that cannot serve as an evaluation set.

## C2. THE ACCEPTANCE THRESHOLD CENSORS EXACTLY THE FAILURES IT MUST LEARN FROM — OCR + layout

Stage 3 accepted a line as GT only when the model's own reading was close to the reference. But when a band
clips scripture, **the OCR never contains the clipped words** — so those lines score badly and are discarded.
Labels survive only where the incumbent was already right. This is not label noise; it is deterministic,
class-conditional censoring correlated with the exact defect the campaign exists to fix.

## C3. THE BUILD ORDER IS A CYCLE PRESENTED AS A SCHEDULE — OCR + layout

Alignment needs a recognizer; the recognizer needs alignment GT; the region model needs alignment for labels;
alignment needs regions for lines; the region model's gate is the board, which the recognizer produces. There
is no entry point. The plan implicitly resolved this by using the incumbent geometry — the very thing it
claimed to be removing.

## C4. THE VARIANT-LATTICE LIGATURE BOOTSTRAP CANNOT WORK — OCR, decisively

- A CTC model places posterior mass only on symbols **in its codec**. CATMuS declines ligatures, so `ﬁ` is
  *unscoreable*, not low-scoring. Add it untrained and its logit sits at −∞; the lattice picks `f`+`i` with a
  huge margin at every locus, forever. Round one yields **zero** ligature GT and the margin experiment
  measures an undefined quantity.
- Even trained: posteriors are peaky and blank-dominated; one ligature symbol and two kerned sorts explain
  identical pixels. There is no likelihood asymmetry to exploit. Same for `ſ`/`f` — a few pixels of nub.

**Ligature-versus-digraph is a typographic question, not a sequence-decoding one.**

## C5. PER-COLUMN CHARACTER MSA MANUFACTURES READINGS NO WITNESS CONTAINS — alignment

The worked example is unanswerable:

```
w1 ſ o n n e     w4 ſ o n n e
w2 ſ o n - -     w5 ſ o ñ - e      col3 = {n×5, ñ×1}   col4 = {n×4, gap×2}
w3 s o n n e     w6 ſ o n n -      → restored  ſ o ñ n e
AR ſ o n n e
```

`ſoñne` is a reading no witness holds and no compositor set. Cause: `æ`↔`ae`, `ﬁ`↔`fi`, `ã`↔`an`, `&`↔`and`
are **1↔2 correspondences** that a column matrix cannot express, so every witness downstream of a ligature is
shifted one column for the rest of the word.

## C6. THE WITNESSES ARE NOT INDEPENDENT, SO k-OF-n IS DECORATIVE — alignment + measurement

All six recognizers descend from one CATMuS parent, are fine-tuned on GT generated by one alignment against
one ARCHAIC, and pass through one preprocessing path. Correlated error is counted as corroboration. And the
training loop makes the wrong votes *unanimous* — while image adjudication was specified to fire only on
**close** votes. **The safeguard was anti-correlated with the failure.**

## C7. THE DRIFT LOOP WAS UNGUARDED — alignment + measurement, same mechanism

ARCHAIC anchors alignment → aligned lines become GT → recognizers train on it → the six agree with ARCHAIC
*because they were trained on it* → concurrence is met more easily → more write-back → the board rises.
Concrete: a systematic `s_dismas` error at 400 loci is accepted as GT, learned by all six, emitted
unanimously, never image-adjudicated, and stamped into ARCHAIC with provenance reading "6/6, high
confidence". The pixels were never consulted. **Board up, transcript down.**

The guard also protected only *glyph* identity — but restoration changes *spelling*, and `ſon`→`ſonne`
survives a fold that neutralises `ſ/s`.

## C8. RARE-CLASS COLLAPSE WILL DELETE THE INVENTORY THE PROJECT EXISTS FOR — OCR

`ﬃ ﬄ ꝑ ꝓ ꝗ q̃` occur tens of times corpus-wide. Under CTC a class with under ~100 instances is essentially
never emitted — the loss is lower if the model prints blank plus the frequent neighbour. Codec size is
harmless; the **imbalance** is fatal. Also: mixed NFC/NFD across codec, GT and scoring silently produces
duplicate codec entries and a CER that is simply wrong.

## C9. THE 0.5% TARGET IS NOT SUPPORTED BY THE WORK I CITED — OCR + measurement

Reul's sub-0.5% is book-specific models on human-corrected GT with a **small alphabet**, voting away
*stochastic* error. Al Azawi's 0.40% is a **supervised** voter trained on aligned GT. Neither supports 0.5%
over a ~400-class diplomatic alphabet on 1582 print. And inter-transcriber agreement on macron-versus-speck
and `ſ`-versus-`f` will not itself be 99.5% — **a target below the human noise floor is incoherent**, and no
probe of that floor was planned.

## C10. MY OWN CORRECTED MEASUREMENTS ARE STILL WRONG — measurement

The 0.9879 is a **maximum over 11 candidate alignments**, upward-biased by construction, with no null
distribution — and biblical verse text is formulaic enough that any two DR-ish texts would score well at ±5.
It was computed on the **intersection** (the mutually-covered, therefore easy, subset) while coverage was
computed on the **union**, with neither stated. And it folds long-ſ, æ, case and punctuation — *the very
dimensions the product exists to preserve* — then licenses repairing the **glyph authority** from a companion
that does not preserve glyphs.

Coverage's union denominator hides common-mode absence, counts a verse as covered when its content is the
spliced apparatus of §1.2, and confuses versification granularity with incompleteness.

## C11. THE EDITORIAL PREMISE IS WRONG AS STATED — scholar

"Diplomatic" means the transcription of **one document — one copy, one setting of type**. Voting glyphs across
six witnesses spanning fifty years produces a text whose readings **co-occur on no page ever printed**. Every
early modern copy differs; stop-press correction means two copies of the same forme differ. Compositor
preferences (`doe/do`, `-nesse/-nes`, medial-ſ habits) are *evidence*, and voting averages them away.

The fix is not to abandon collation but to adopt **copy-text discipline** (Greg/Bowers/Gaskell): a declared
copy-text per tome; **accidentals follow copy-text absolutely**; other witnesses may supply readings only
where the copy-text is physically illegible or demonstrably a press error; every such emendation recorded.

That also dissolves §7.4 — the 1630s editions become **substantive witnesses only, always**, never touching
orthography, with no circular "abstain where they differ" rule to implement.

**And `s_dismas` cannot be the glyph authority.** It is an unprovenanced modern web transcription of unknown
base edition, documented in our own §1.2 to splice annotation into scripture, covering 69.7%. The glyph
authority is **the image**.

**Pseudo-archaic is fabrication.** Synthesised archaic spelling cannot appear in a diplomatic transcript at
all, flagged or not. Those loci are transcribed from the scans or they are gaps.

## C12. THE PLAN OMITS THE APPARATUS THAT MAKES AN EDITION CITABLE — scholar

Missing and mandatory: per-source bibliographic identification (STC/ESTC, repository, shelfmark, scan
provenance, copy imperfections); a statement of editorial principles; **page and signature references in the
output** (`|Aa3v|`), without which no reading can be checked; a list of emendations with siglum; a record of
rejected variants; uncertainty encoding at every voted locus; an `unclear`/`gap` mechanism — *there is
currently no way to say "I cannot read this"*; a TEI header; press-variant consideration.

## C13. THE GLYPH INVENTORY IS PART MEDIEVAL FANTASY AND MISSES WHAT IS ACTUALLY THERE — scholar

Anachronistic for DR roman/italic type: `ꝛ` (r-rotunda is blackletter), `ꝑ ꝓ ꝗ` (Latin scribal brevigraphs),
MUFI PUA generally. **Missing and actually present**: italic/roman contrast as a *semantic* (proper names,
quoted OT, annotations); small capitals; swash italic capitals; blackletter in headings; capital `VV` for `W`
in display sizes; turned letters and wrong-fount sorts (**genuine compositorial errors a faithful transcript
must preserve, and voting will systematically "correct"**); ligature presence-vs-absence as a recorded fact;
punctuation practice; hyphenation and line-end.

## C14. JBIG2 IS THE WORST POSSIBLE CARRIER FOR THIS DISTINCTION — scholar

The plan flags JBIG2 symbol substitution as UNMEASURED and then builds the preferred raster path on the 1-bit
mask. Lossy symbol matching merges visually similar glyphs, and **`ſ`/`f` is the canonical failure case** —
precisely the distinction the edition rests on. Also: resampling a 1-bit image without converting to 8-bit
first is nearest-neighbour aliasing that removes the nub and the macron.

## C15. SMALLER, STILL REAL

- **Iterating over ARCHAIC drops 22.6% of the Bible from collation entirely** (alignment). Iterate the union.
- **§5 and §6 contradict each other** on whether pseudo-archaic enters GT (measurement).
- **The BOOK level of the model hierarchy is statistically undecidable** — distinguishing 0.60% from 0.50%
  needs ~10⁵ held-out characters per model, times ~440 scopes; and the books needing it most have no archaic
  witness, so no GT (OCR).
- **Cross-fold voters all share a parent**, which Reul specifically found votes worse (OCR).
- **Raising H without touching the pooling stack** changes the receptive-field aspect ratio the filters were
  fitted for; sweep jointly, evaluate on ſ/f and macron classes, not aggregate CER (OCR).
- **The 2-of-3 fusion has two correlated voters** (distant supervision and the geometric prior both descend
  from `PAGE_OVERRIDE`), so A∧C always carries and the fusion launders the incumbent (layout).
- **Region polygons from aligned-line-box hulls inherit the band's boundary error by construction**, making
  the boundary-error gate unreachable in expectation (layout). Regions must come from **ink**.
- **DropCap is a rare single-instance nested class** that segtrain will underfit and that fragments MainText;
  it is an alignment-deficit detection problem, not a region problem (layout).
- **Marginalia labels are sparse in the wrong way** — every unlabelled marginal block becomes an implicit
  negative and teaches suppression (layout).
- **Whole books have no archaic witness, so no distantly-supervised labels at all** — the training set is a
  non-random book subset (layout).
- **Citation overreach**: arXiv:2511.08903's 88.2 AP is **at 5% labels** — evidence *for* a seed set, not
  against one; arXiv:2112.12703's leverage was TEI structural markup that our verse-keyed plaintext does not
  have; "we are a better case than theirs" is false and is deleted — four witnesses corroborate *word
  identity*, never *region geometry*.
- **The board gate change bundles +122 and −18 and nets them**; report separately against a frozen board.
- **"WARNING class, not a silent pass" is itself a silent pass** under the project's own rule — a
  below-threshold unit converted to a terminal non-blocking state. It must be OPEN and blocking.
- **§0.1's self-diagnosis lists four cases where caution was wrong and zero where it was right** — a bias
  diagnosis with selection bias in it, producing a rule with no terminating state.
